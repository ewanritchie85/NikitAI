how a message gets routed

One entry point, a growing team

Every message goes through the same orchestrator first. A cost-effective model decides which sub-agent it belongs to. If it's not clear, NikitAI asks rather than guesses.

The specialists

Each sub-agent has its own system prompt, its own tools, and its own conversation history — switching topics doesn't confuse one agent with another's context.

Organiser

Outlook — email & calendar

claude-sonnet-5

Acts as your personal Outlook assistant. Understands your inbox and calendar, drafts email in your preferred style, organizes messages and folders, explains your schedule, and prepares calendar updates, while keeping you in control of all final actions.

  • list_emails, get_email, search_emailsread the inbox
  • send_emailrequires approvaldrafts a reply, waits for you to confirm
  • list_mail_folders, move_email, create_mail_folderlow-risk, reversible writes
  • delete_mail_folderrequires approval
  • list_calendar_events, create_calendar_eventrequires approval

Platform Nerd

Home network & hosting

claude-sonnet-5

Maintains an up-to-date understanding of your home network, Linux hosts, and self-hosted services by reading and updating project logs and configuration notes. Answers questions and diagnoses problems using real networking principles rather than generic assumptions.

  • list_log_files, read_log_filereads your infra notes, path-confined to one folder
  • append_to_logrequires approvalappend-only — can't overwrite or create new files

nikitai --show-safety

Nothing writes without approval

Every sub-agent follows the same rule, enforced in code — not just prompted for.

reads never pause

Listing emails, checking the calendar, reading a log file — none of it needs confirmation.

writes always ask

Sending mail, creating events, deleting folders, logging a config change — every one shows what it's about to do first.

enforced in code

The gate is a hard check before the tool runs — not a system-prompt instruction the model could talk itself out of.
